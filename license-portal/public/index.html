Khóa ký hiện hành

Quan trọng: khóa công khai (public key) phải được dán vào app để app xác thực license. Khóa riêng (private key) chỉ nằm trong Cloudflare Worker Secret — không bao giờ commit vào git.

Cách đưa public key vào app

// ClassLibraryMT/Licensing/LicenseKeys.cs
public const string CurrentKeyId = "<KEY_ID>";
public const string CurrentPublicKey =
    "<PUBLIC_KEY_BASE64>";

public static IReadOnlyDictionary<string, string> All { get; } =
    new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase)
    {
        [CurrentKeyId] = CurrentPublicKey,
    };

Sau khi sửa file, build lại app rồi phát lại cho khách hàng.
